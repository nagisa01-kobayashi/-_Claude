# 困りごとカード（確定案・6種類）

`バレーボール単元_設計方針_確定版.md` の暫定候補を、重複を整理しゾーン対応で再構成したもの。
各カードは「困りごと（掲示用の言葉）」「考えられる原因」「練習方法（3段階）」「達成基準」「見る手本」の4点セット。

## 段階（レベル1〜3）の呼び方・達成基準の考え方（確定）

- 呼び方は**「レベル1・2・3」のまま**（ブロンズ／シルバー／ゴールド等は不採用）。
- 判定方法は2種類を使い分ける。
  - **客観テスト型**：本数・回数・「狙った場所に入ったか」など、結果で判定できるもの。生徒本人（または相手役）が記録カードに記入して自己申告。何度でも挑戦可、できたと思ったら次のレベルへ。合格ラインは**全レベル共通「5本中3本」**に統一。
  - **フォーム確認型**：体の使い方・姿勢など、結果だけでは判定しづらいもの。まず「チェックポイント表」を見ながら生徒同士（ペア）で確認 → 自信がない／意見が割れたときだけタブレットで撮影して先生に見せる。
- **「一歩」の考え方**：味方へのプレー（トス・レシーブでつなぐ）は「相手（味方）が動かずに済む精度」、逆にアタックは「相手が動かないと触れない精度」という対になる基準にする。バレーボールの技術として筋が通り、判定も客観的になる。

---

## ① サーブが入らない（サーブゾーン）
- **考えられる原因**：トスが安定しない／打つ強さ・角度が定まらない
- **練習（3段階）と達成基準**
  1. 近い距離から相手コートに入れる → 5本中3本、相手コートに入る（客観テスト）
  2. 通常の距離からコートに入れる → 5本中3本、相手コートに入る（客観テスト）
  3. 指定エリア（狙った場所）に入れる → 打つ前に宣言したエリアに5本中3本入る（客観テスト）
- **見る手本**：QR動画「アンダーサーブ／サーブの基本フォーム」

## ② レシーブがつながらない（レシーブゾーン）
- 「ボールの下に入れない」「前に飛ばない」を統合
- **考えられる原因**：ボールの落下点への移動が遅い／面（腕）の向きが不安定
- **練習（3段階）と達成基準**
  1. 山なりで投げてもらったボールを、壁または相手に返す（自由）→ 5本中3本返せる／姿勢3点チェック（①ひざを曲げている②うでをまっすぐ伸ばしている③ボールの正面に入っている）（本数=客観テスト、姿勢=フォーム確認型）
  2. 決まった場所に立ち、正面に来たボールを返す → 5本中3本、正面に返せる（客観テスト）
  3. 位置を変えながら来るボールに、狙った場所へ返す → 5本中3本、味方が一歩以内の移動で処理できる位置に返せる（客観テスト・味方が判定）
- **見る手本**：QR動画「アンダーレシーブの基本姿勢」

## ③ トスが安定しない・狙った場所に上げられない（トスゾーン）
- **考えられる原因**：手の形・上げる高さが安定しない
- **練習（3段階）と達成基準**
  1. 自分でトスを上げてキャッチする（感覚づくり）→ 頭上30cmほどの高さに5回連続で上げられる／手の形3点チェック（①手が三角形②ひじを軽く曲げている③ボールを迎えに行っている）（回数=客観テスト、手の形=フォーム確認型）
  2. フープ・的をねらってトスする → 5本中3本、フープ・的に入る（客観テスト）
  3. 味方が打ちやすい位置・高さへ連続でトスする → 5本中3本、味方が一歩も動かずに打てる位置・高さへ上げられる（客観テスト・味方が判定）
- **見る手本**：QR動画「オーバートスの手の形」

## ④ 返球（アタック・返し方）がどこに返せばいいかわからない（アタックゾーン）
- **考えられる原因**：相手コートの空いている場所を見る余裕がない／打つ・落とすの選択肢が少ない
- **練習（3段階）と達成基準**
  1. 好きな場所を狙って打つ・落とす → 5本中3本、コート内に入れて返せる（客観テスト）
  2. マーカーなど目標を狙う → 5本中3本、目標に当てる／近くに落とす（客観テスト）
  3. 相手（の空いている場所）を見て、狙う場所を選んで打つ → 相手役が一歩以上動かないと触れない場所へ5本中3本打てる（客観テスト・相手役が判定）
- **見る手本**：QR動画「アタック／落とし方のコツ」

## ⑤ 仲間とぶつかる・ボールを避けてしまう（連携・声かけ）
- **考えられる原因**：誰が取るかの声かけ・合図がない／自分の担当エリアの意識がない
- **練習（3段階）と達成基準**（本数・回数だけで判定できるよう客観化）
  1. 「はい！」など声を出す練習 → 1分間のパス練習中、声を8回以上出せた（ペアがカウント）（客観テスト）
  2. 2〜3人でエリアを決めて声をかけ合いながらラリー → 5往復のラリー中、ぶつかった回数0回、かつ毎回ボールに触れる前に声が出ている（ペアが記録用紙にチェック）（客観テスト）
  3. チーム全員でポジションを意識し、声をかけ合いながらゲーム形式のラリー → 3分間のラリー中、ぶつかった回数0回、かつコール回数がボールに触れた回数と同数以上（チームで記録）（客観テスト）
- **見る手本**：QR動画「声かけの例」（生徒モデル推奨）

## ⑥ 3回で返せない・ラリーが続かない（つなぐ・総合）
- レシーブ→トス→アタックの一連の動きがうまくつながらない、という複合的な困りごと
- **考えられる原因**：①〜③個別はできても、つなぐタイミング・移動が間に合わない
- **練習（3段階）と達成基準**
  1. 2人でレシーブ→トスだけをつなぐ → 連続3回、相手が一歩以内の移動でつなげられる（客観テスト）
  2. 3人でレシーブ→トス→返球までつなぐ → 連続3回、次の人が一歩以内の移動でつなげられる（客観テスト）
  3. チームでラリーを続けることを目標にミニゲーム → 3回以内で相手コートへ返すラリーを3本連続で成立させる（客観テスト）
- **見る手本**：QR動画「3段攻撃のつなぎ方」

## 確定事項（旧・確認したいこと）
- 6種類・書きぶりで確定。
- ⑥「3回で返せない」は①〜③ができた生徒が次に挑戦する統合カードという位置づけで確定。
- 段階（レベル1〜3）の呼び方は「1・2・3」のまま、達成基準は上記の通り確定。

# サッカー単元 第1時 指導案「オリエンテーション・試しのゲーム」

## ■ 本時の位置づけ

単元10時間のうち第1時。単元を貫く問い「全員が楽しめるサッカーの試合とは、どんな試合だろう?」の出発点となる時間。技能指導は行わず、**試しのゲームを通して生徒自身に課題を発見・言語化させる**ことに専念する。

## ■ 本時の目標

- 試しのゲームを通して、現状のサッカーの試合における「楽しめた点」「楽しめなかった点」を自分の経験から具体的に言語化できる。
- 単元のゴール(全員が楽しめる大会を自分たちでつくる)を理解し、見通しを持つ。

## ■ 本時の評価規準

- 【主体的に学習に取り組む態度】①ルールやマナーを守り進んで取り組もうとしている(試しのゲームでの様子を観察)
- 【思考・判断・表現】③の素地(自分の経験から課題を見つけようとしている)※本格的な評価は3時間目以降

## ■ 準備物

- サッカーボール(コート数に応じて複数)、ビブス(チーム分け用)、振り返り用ワークシートまたはタブレット(Googleフォーム)

## ■ 時間配分・展開

| 時間 | 学習活動 | 教師の発問・指示 | 予想される生徒の反応 | 教師の切り返し・支援 | 留意点 |
|---|---|---|---|---|---|
| 0〜3分 | 集合・あいさつ | 「今日から10時間かけて、サッカーの単元を行います。今日はまず、みんなでサッカーをやってみましょう」 | — | 単元の詳しい説明はせず、まず体験させることを優先する | 見通しを持たせすぎず、体験後の振り返りで深める設計 |
| 3〜8分 | 準備運動 | 「怪我をしないように、しっかり体を動かしましょう」 | — | 特に足首・股関節を重点的に | 校庭の状態(石・段差)を事前確認 |
| 8〜13分 | チーム編成 | 「今日は経験のある人・少ない人が混ざるようにチームを分けます」 | — | — | 教師があらかじめ技能を分散したチーム表を用意しておく(生徒任せにしない) |
| 13〜33分 | 試しのゲーム(ミニゲーム形式、複数コートに分けて同時進行) | 「まずは自由にプレーしてみましょう。今日は特別なルールはありません」 | 積極的にプレーする生徒、あまりボールに関われない生徒など、様々な参加の仕方が見られる | 教師は各コートを回り、参加の偏りや技能差の様子を観察・メモしておく(次時以降の教材化のため) | 接触プレーへの注意、キーパーが固定されていないか等も観察 |
| 33〜35分 | 集合・水分補給 | 「集まってください。少し水分を取りましょう」 | — | — | 熱中症対策(季節に応じて時間調整) |
| 35〜45分 | 振り返り(全体) | 発問①「今のゲーム、楽しめた人?」(挙手) | 挙手が割れる、または多くが手を挙げるが一部挙げない生徒がいる | 「楽しめた人と、そうでもなかった人がいますね。両方の理由を聞いてみましょう」 | 挙手できない・したくない生徒への配慮(無理に発言させない) |
| | | 発問②「楽しめた人は、どんなところが楽しかった?」 | 「点が取れて嬉しかった」「みんなでボールを回せた」「走るのが楽しかった」 | 「なるほど、"点を取れたこと"や"ボールに関われたこと"が楽しさにつながっているんですね」 | 発言を板書またはタブレットで記録し、可視化する |
| | | 発問③「逆に、あまり楽しめなかった人は、どんなところが楽しめなかった?」 | 「ボールがあまり回ってこなかった」「一部の人ばかりボールを持っていた」「シュートを打てなかった」「キーパーばかりやらされた」 | 「"ボールを持てる人が決まってしまう"というのは、実はサッカーではとてもよくある悩みです。今日みんなが感じたことは、決して特別なことではありません」 | 特定の生徒を名指しで責めるような雰囲気にならないよう、"サッカーというスポーツにありがちな構造の話"として扱う |
| | | 発問④「もし『全員が楽しめる試合』にするとしたら、今日のどこを変えたらいいと思う?」 | 「ルールを変える」「チームを変える」「もっと簡単にする」など、断片的なアイデアが出る | 「良いアイデアですね。これから10時間かけて、まさにそれをみんなで考えて、自分たちの大会を作っていきます。今日出た意見は、これからずっと使っていくので大事に覚えておいてください」 | ここで結論を急がせない。あくまで「問いを持ち帰る」ことがゴール |
| 45〜48分 | 単元のゴール共有 | 「この単元のゴールは、"全員が楽しめるサッカーの試合とは何か"をみんなで考えて、自分たちで大会を作り、運営することです。ルールも、参加人数も、審判も、全部自分たちで決めていきます」 | 期待と不安が入り混じった反応が予想される | 「難しく考えなくて大丈夫。今日感じたことが、そのままこれからの授業の材料になります」 | 生徒運営という単元の特徴を前向きに伝える |
| 48〜50分 | 振り返り記入・あいさつ | 「今日感じた"楽しかったこと"" 楽しめなかったこと"を、フォームに記入してください」 | 各自記入 | 記入が難しい生徒には個別に一言添えて促す | 次時冒頭で全体傾向を共有するため、当日中に回収・集計する |

## ■ ICT活用

- 振り返りをGoogleフォームで収集し、教師が当日中に集計。次時(第2時)冒頭でクラス全体の傾向(例:「ボールが集中した」と答えた人が◯割)を提示し、課題を可視化する。
- ICTが使えない場合の代替:紙の振り返りカードに記入させ、教師が黒板に集計結果を書き出す。

## ■ 安全配慮

- 準備運動を入念に行う(特に接触プレーが起こりやすいサッカーでは股関節・足首のケアを重視)。
- 試しのゲーム中、キーパーやディフェンスの接触プレーに教師が目を配る。
- 水分補給のタイミングを明確に区切り、熱中症の兆候がないか確認する。

## ■ 形成的評価

- 試しのゲーム中の観察:誰がボールに関わる機会が少ないか、技能差がどの程度あるかを教師がメモ(個票または全体観察シート)。この情報は2時間目以降のチーム編成・個別配慮に活用する。
- 振り返りフォームの記述内容:「楽しめなかった理由」の記述の具体性を確認し、次時の技術指導・ルール検討の教材として活用する。

## ■ 教育的根拠

- 最初から技能指導に入らず、まず試しのゲームを行い、そこで生じた「楽しめなさ」を教材化する流れは、Teaching Games for Understanding(TGfU)の考え方(ゲーム経験→問題発見→技能・戦術理解→再ゲーム化)に基づく。生徒自身の実感から出発することで、以降の技能練習やルール検討の必然性・当事者意識が高まる。
- 「なぜ楽しめなかったか」を生徒自身に言語化させる活動は、思考・判断・表現の出発点であると同時に、自己調整学習における「現状把握(モニタリング)」の第一段階に相当する。

**メリット**:生徒が単元のゴールを"自分ごと"として捉えやすくなる。
**デメリット**:初回の試しのゲームで極端に消極的な生徒がいると、振り返りで発言しづらくなる可能性がある→無記名のフォーム活用や、グループ内での共有を併用するなどの配慮が有効。

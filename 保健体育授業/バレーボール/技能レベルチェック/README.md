# バレーボール技能レベルチェック（生徒配布用）

## 概要

アンダーハンドパス／オーバーハンドパス／サーブ／スパイク／ブロックの5技能について、
生徒が「今の自分がどのレベルにいるか」を客観的に把握できるよう、3段階のレベルと
イラストをセットにした自己チェック表。困りごとカード（`バレーボール学習カード_生徒用ワークシート`）
の「練習レベル1・2・3」表記と対応させ、単元全体の自己調整学習サイクル
（ゲーム→困りごと発見→練習を選ぶ→ゲームで確かめる）に接続する教材として作成した。

- 正本（Googleドライブ）: 単元フォルダ「バレーボール」内に本ファイルと同内容を記録
  （PDF実体は担当者チャットに直接送付、閲覧用リンクはドライブのメモ内に記載）
- 本リポジトリはソース（HTML）とPDFの履歴管理用

## レベル設計の考え方

各技能で共通する見せ方（ポーズの文法）:

| レベル | 意味 | イラストの見せ方 |
|---|---|---|
| レベル1 | フォームができる | 静止したフォームのみ。ボールはまだ動いていない |
| レベル2 | 安定してできる | ボールが真上／相手コートへ、まっすぐ・一般的に動く |
| レベル3 | ねらってできる | ボールが仲間や狙った場所（的マーク）に正確に届く |

「上手い／下手」ではなく成長の段階として提示し、レベルは順番に上がらなくてもよいこと、
今日できたところに◯をつければよいことを表内に明記した（技能差への配慮、失敗体験の
量的コントロールという単元の設計方針と一致させるため）。

## 技能ごとのレベル文言

| 技能 | レベル1 | レベル2 | レベル3 |
|---|---|---|---|
| アンダーハンドパス | アンダーハンドパスの形が作れる | 球をまっすぐ真上に上げられる | ねらった仲間にふんわり上げられる |
| オーバーハンドパス | オーバーハンドパスの形が作れる | 球をまっすぐ真上に上げられる | ねらったところに正確に上げられる |
| サーブ | 相手コートに入れられる | ねらったエリアに入れられる | 相手が取りにくい所に打てる |
| スパイク | 助走とジャンプのタイミングが合う | ボールを相手コートに打ち込める | ねらったコースに打ち分けられる |
| ブロック | ジャンプのタイミングが合う | 手をネットの上に出せる | 相手の攻撃を止められる |

## イラストについて

写実的なAI生成画像ではなく、シンプルな線画のピクトグラム（棒人間＋ボール＋ネット／的マーク）
を自作した。レベルごとに人物の線の色を変える（レベル1＝青灰／レベル2＝緑／レベル3＝橙）ことで、
文言を読まなくても色と絵だけでレベルの違いが直感的にわかるようにしている。
中学生が実際の場面をイメージしやすいよう、以下の3点をイラストの文法として統一した。

1. フォーム確認（静止・ボール静止）
2. 一般的な成功（ボールがまっすぐ動く）
3. 狙った成功（仲間の手元／的マークに届く）

## 使い方（想定）

1. 授業内でこの表を配布し、生徒が自分の現在地に◯をつける。
2. 「学習カード」の困りごと一覧から練習したい技能を選ぶ際の判断材料として使う。
3. 単元後半で再度チェックし、変化を振り返りカードに書かせる。

# バレーボール単元　⑦学び方を学ぶ時間＋自己調整学習①（授業案）

`弘済会実践論文/単元_時間配分_確定版.md` の⑦番目のコマ。当初「学び方を学ぶ時間」「自己調整学習①」を別コマとしていたが、**前半10分（学び方）＋後半40分（自己調整学習①）の1コマに統合**した。これにより残りコマ数が7→6となり、「残り5〜6時間」という見立てと合致した。

- 1コマ50分、教師1人で2コート（通常バレー／緩和バレー）を見る

## 授業目標

- 試合①で感じた「困りごと」を、自己調整学習のサイクル（PDCA合言葉）と結びつけて理解する
- ハンドリング体験を通して、PDCA合言葉（なぜ？／トライ！／コツは？／より良く！）を自分の実体験と結びつけて覚える
- 困りごとカードを選び、振り返りシートに記録しながら個別課題学習に取り組み始める

## 展開（前半10分：学び方を学ぶ時間）

| 時間 | 内容 | 教師の発問・進め方 |
|---|---|---|
| 0-1分 | 導入 | 「今日から自己調整学習スタート」 |
| 1-5分 | ハンドリング体験 | バレーボールを手のひらに乗せ、落とさず一回転させるチャレンジ。まず自由に挑戦（1分）→「できた人？できなかった人、なんでだと思う？」（**なぜ？**）→もう一度、変えて挑戦（**トライ！**）→「手の甲を下からのぞきこむように見上げてみて」とヒント→「できた人、さっきと何が変わった？」（**コツは？**）→「もっと速く／反対の手は？」（**より良く！**を軽く体験） |
| 5-8分 | 名前をつける | 「今やったこの流れが『なぜ？→トライ！→コツは？→より良く！』という学び方そのもの」とラベリング。ポスター掲示。試合①の困った場面にも同じ言葉を軽く当てはめる |
| 8-10分 | 自己調整学習への接続 | 「体育館に掲示してある困りごとカードを見て、自分の課題を選んで、この振り返りシートに記録しながら練習してください」 |

## 展開（後半40分：自己調整学習①）

- 各自、困りごとカード①〜⑥から取り組むものを選び、コート内の該当ゾーンで個別・ペア練習
- 「バレーボール振り返りシート」（スプレッドシート、既存フォーマット）に記録
  - うまくいかなかったこと／どの技能か → 困りごとの発見
  - 自分の課題 → **なぜ？**の言語化
  - まとめ（自分でつかんだコツ・仲間からのアドバイス） → **コツは？**
  - 振り返り（次試したいこと・課題） → **より良く！**
  - 先生からのコメント欄 → 教師のフィードバック
- 教師は2コートを巡回し、必要に応じてシートにコメントを記入、または直接声かけ

## 環境設定：この時間はネットを立てない

困りごとカード①〜⑥の練習内容を精査した結果、①②③⑤はネット不要、④⑥もコーン・テープ等の目印で代替可能と判断し、**この時間はネットを設営しない**こととした（設営・撤去の時間を、40分しかない自己調整学習の時間から削らないため）。

| カード | 代替の目印 |
|---|---|
| ①サーブ | 床にテープ・コーンで狙うエリアを表示 |
| ④アタック | コーンの上に紐を張るなど簡易的な目印で「相手コート」を表現 |
| ⑥つなぐ | エリア目標（コーン等）に置き換え |

次回「⑧自己調整学習②＋プチ試合」以降、実際にネットを使う場面で改めて設営する。

## 次時へのつながり

⑧自己調整学習②＋プチ試合では、この時間に蓄積した振り返りシートをもとに、個別練習と小規模な試合を組み合わせて中間検証を行う。

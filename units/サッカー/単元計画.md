# サッカー単元計画(生徒運営型)

## 条件

- 学年:3年 / 人数:30〜40人 / 編成:男女共修 / 技能差:経験差が大きい
- 生徒の意識:得意不得意がはっきり分かれている / 施設:校庭コート1面
- ICT:1人1台タブレット活用可 / 単元時数:8時間 / 特別な配慮:なし
- テーマ:生徒が運営する授業(大会運営を含め、すべて生徒主体で進める)

## 単元目標

- **知識及び技能**:サッカーの特性や技術・ルールを理解し、状況に応じたボール操作(パス・トラップ・ドリブル・シュート)と空間を作る動きによって、チームの作戦に基づいた攻防を展開できるようにする。
- **思考力、判断力、表現力等**:自己やチームの課題を発見し、技能差を踏まえた練習・作戦を工夫するとともに、大会の規則や運営方法を仲間と話し合って決め、その意図を他者に伝えることができるようにする。
- **学びに向かう力、人間性等**:サッカーに主体的に取り組み、フェアなプレイを大切にし、大会運営の役割に責任を持って取り組み、一人一人の技能差を認め合おうとする態度を養う。

## 評価規準

### 知識・技能
1. ルール・技術の名称や行い方を理解している
2. 状況に応じてパス・トラップ・ドリブルができる
3. 優位な空間に動くことができる

### 思考・判断・表現
1. 技能・課題に応じた練習方法を選んでいる
2. チームの特徴に応じた作戦を立てている
3. 大会の規則(試合形式・反則の基準など)を、参加者全員が楽しめるように話し合って決めている
4. 考えたことを仲間に理由とともに伝えている

### 主体的に学習に取り組む態度
1. ルールやマナーを守り進んで取り組もうとしている
2. 技能差のある仲間と教え合い、認め合おうとしている
3. 審判・得点・記録・進行などの運営の役割を、責任を持って果たそうとしている
4. 場や用具の安全を確かめている

## 生徒が完成させる「大会要項」の骨組み

| 項目 | 生徒が決めること | 教師が最終確認すること |
|---|---|---|
| 大会名・目的 | 大会の名前、めあて(勝敗だけでなく何を大事にするか) | ― |
| 試合形式 | リーグ戦/トーナメント、1試合の時間、コート数(校庭1面という制約を踏まえる) | 時間内に収まるか |
| ルール | 反則の基準、得点方法、技能差への配慮ルール | 安全面(危険なプレイの扱い) |
| 運営体制 | 審判・得点係・タイムキーパー・進行(放送)・記録係の役割分担とローテーション | 全員に役割が回っているか |
| 安全・救護 | 準備運動、用具点検、けが発生時の連絡ルート | 最終的な安全管理は教師が確認・責任を持つ |
| 表彰・まとめ | 表彰の仕方、大会後の振り返り方法 | ― |

## 8時間計画

| 時間 | ねらい | 内容 |
|---|---|---|
| 1 | オリエンテーション・実態把握 | チーム編成(技能分散)、試しのゲーム、「自分たちで大会を作る」という単元のゴールを共有 |
| 2 | ボール操作①(パス・トラップ) | ドリル、タブレットでフォーム確認 |
| 3 | ボール操作②(ドリブル・シュート) | ドリル、ミニゲーム |
| 4 | 空間を作る動き+大会要項づくり① | タスクゲーム/大会の目的・試合形式・ルールをチーム代表で話し合う |
| 5 | チーム作戦+大会要項づくり② | 作戦づくり、ゲーム①/運営役割を分担し、ルールを確定 |
| 6 | リハーサル大会 | 運営役割を実際に担当してゲーム②を実施、運営面の課題を洗い出して修正 |
| 7 | 本大会① | 生徒運営でリーグ戦、教師は安全確認と見守りに徹する |
| 8 | 本大会②・まとめ | 大会継続・表彰、単元の振り返り(技能面・運営面の両方) |

## 技能差への配慮

- チーム編成は経験者を各チームに分散する
- ドリル・タスクゲームに易しい版/発展版を用意する
- 経験者には「教える役割」を持たせ、指導と協働学習を兼ねさせる

# ChatGPT壁打ち履歴 抽出プロンプト

ChatGPTでの過去の壁打ち（ブレスト）会話を、Claudeに引き継ぐためのMarkdown形式で
書き出してもらうためのプロンプトです。使うときは「【対象にする会話】」の欄を埋めてから、
ChatGPTにそのまま貼り付けてください。

出力されたMarkdownをコピーして `.md` で保存し、Claudeにアップロードしてください。

---

## 使い方

1. 下記プロンプトの `【対象にする会話】` の空欄に、対象範囲を書く
   （例：「保健体育の授業実践や弘済会の論文について相談した会話すべて」）
2. ChatGPTに貼り付けて実行
3. 出力されたMarkdownコードブロックをコピーし、`.md` ファイルとして保存
4. アップロード前に、生徒の実名・学校名が残っていないか目視確認する
5. Claudeにアップロード

---

## プロンプト本文

```
あなたにこれまで相談してきた「壁打ち」の会話を、後で別のAIアシスタント（Claude）に
引き継ぐためのMarkdownファイルとしてまとめてください。

【目的】
今後の作業をClaudeに引き継ぐための資料です。要約しすぎず、具体的なアイデア・数値・
言い回し・まだ迷っている点まで、なるべく漏らさず残してください。

【対象にする会話】
※ここに対象範囲を書いてください（例：「保健体育の授業実践や弘済会の論文について
相談した会話すべて」「◯◯という単元について話した会話」など）
[                                                    ]

【出力形式】
以下の構成でMarkdown形式にまとめてください。

# 壁打ち履歴まとめ（ChatGPT）

## 会話の概要
- いつ頃、何について相談したか（分かる範囲で日付・時系列も）

## テーマ・論点ごとの整理
テーマ（例：単元の工夫、技能差対応、評価方法など）ごとに見出しを立て、それぞれに：
- 話し合った内容・出たアイデア（箇条書きで具体的に）
- 良いと感じた案／採用しようとしていた案
- 検討したが保留・却下した案とその理由
- まだ結論が出ていない論点・迷っていること

## 決定事項・確定している方針
- すでに「これでいく」と決めたこと

## 次にやろうとしていたこと・宿題
- 「次は◯◯を考える」「持ち帰って検討する」となっていたこと

【注意事項】
- 要約で内容を薄めず、固有名詞・数値・具体的な言い回しはできる限りそのまま残してください。
- 会話が複数回・複数スレッドにわたる場合は、時系列がわかるように見出しか小見出しで
  区切ってください。
- 出力は1つのMarkdownコードブロックにまとめてください（コピーしてそのままファイル
  保存できるように）。
- 会話に生徒の実名が含まれる場合は、「生徒A」「生徒B」のように必ず匿名化してください。
  学校名・教職員の実名についても、可能であれば匿名化・伏字にしてください。
```

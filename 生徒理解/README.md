# 生徒理解シートについて（運用ルール）

- このフォルダのファイルには **氏名を記載しません**。生徒は「番号（出席番号）」のみで管理します。
- 番号と氏名の対応表は、このリポジトリには**絶対に置かない**でください。手元の紙・非共有メモ・学校支給端末など、このリポジトリの外で管理してください。
- 記載する項目は現状「嗜好・趣味」「人間関係（交友関係）」「配慮事項・注意点」の3項目です。項目を追加・変更したい場合は都度ご相談ください。
- 配慮事項・注意点はアレルギーやトラブル歴など機微な内容を含み得ます。リポジトリの公開範囲（Private設定になっているか）を定期的にご確認ください。

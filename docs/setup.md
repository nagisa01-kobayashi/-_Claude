# コツッター 導入ガイド（先生向け）

所要時間：30分ほど。最初の1回だけ行います。

用意するもの：学校のGoogleアカウント（先生）、パソコン（作業はパソコンがやりやすいです）、生徒名簿のExcel

---

## 1. 共有ドライブを作る

1. Googleドライブを開き、左の「共有ドライブ」→「＋新規」で、**「コツッター」**という共有ドライブを作ります。
2. 「メンバーを管理」で、ほかの体育の先生を追加します（役割は「コンテンツ管理者」以上）。
   - ⚠️ **生徒は追加しないでください。** 提出された動画は、この共有ドライブのメンバーだけが見られる仕組みです。

## 2. スプレッドシートとプログラムを用意する

1. 共有ドライブ「コツッター」の中で「＋新規 → Googleスプレッドシート」を作り、名前を**「コツッター_データ」**にします。
2. スプレッドシートのメニュー **「拡張機能 → Apps Script」** を開きます。
3. 最初からある `コード.gs` の中身を**全部消して**、このリポジトリの [`gas/Code.gs`](../gas/Code.gs) の中身を貼り付けます。
4. 左の「ファイル」の「＋」→「HTML」を選び、名前を **`Index`** にします（「.html」は自動で付きます）。中身を全部消して、[`gas/Index.html`](../gas/Index.html) を貼り付けます。
5. 💾（保存）を押します。
6. 左の ⚙️「プロジェクトの設定」で、タイムゾーンを **「(GMT+09:00) 日本標準時 - 東京」** にします。

## 3. 初期設定（setup）を実行する

1. エディタ上部の関数の選択で **`setup`** を選び、「▷実行」を押します。
2. 「承認が必要です」と出たら、「権限を確認」→ 自分のアカウントを選び →「許可」を押します。
   - 「このアプリは Google で確認されていません」と出た場合は、「詳細」→「（安全ではないページ）に移動」→「許可」で進みます（自分で作ったプログラムなので問題ありません）。
3. 下の実行ログに「実行完了」と出れば成功です。スプレッドシートに `Settings`・`Students`・`Posts` などのシートができ、共有ドライブに **「コツッター_提出動画（先生のみ）」** フォルダができます。

## 4. Webアプリとして公開する

1. 右上の **「デプロイ → 新しいデプロイ」** を押します。
2. ⚙️（種類の選択）で **「ウェブアプリ」** を選びます。
3. 次のように設定します。
   - 説明：`コツッター`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**「city-niigata.ed.jp 内の全員」**（学校のドメイン名が出ます）
4. 「デプロイ」を押すと **ウェブアプリのURL** が出ます。これをコピーしておきます。

> 「次のユーザーとして実行：自分」なので、生徒はスプレッドシートやドライブに直接はアクセスできません。データは必ずアプリを通して読み書きされます。

## 5. アプリで最初の設定をする

コピーしたURLを開くと、先生の画面が出ます（setupを実行した先生は、自動で管理者になります）。

1. **設定 → 先生（管理者）**：自分の名前を「名前を変更」で直し、ほかの体育の先生を追加します。
2. **設定 → 生徒名簿**：Excelで「学年・組・番号・氏名・メールアドレス」の5列をコピーして貼り付け、「名簿を取り込む」を押します。Excelファイル（.xlsx）を選んで読み込むこともできます。
3. **設定 → 授業集団**：「2-1・2-3」「2-2・2-4」「3-3・3-4」が最初から入っています。必要なら直します。
4. **設定 → 単元**：マット運動と跳び箱運動が最初から入っています。技や場面タグを直せます。
5. **設定 → NGワード**：最初のリストを確認し、学校の実態に合わせて足したり消したりします。

## 6. 生徒に配る

1. **まず生徒用のテストアカウントで1回開いて**、投稿できるか確かめてください。
   - 学校のGoogle管理設定によっては、生徒アカウントでApps Scriptのアプリが開けないことがあります。その場合は、市の情報担当に「ドメイン内のApps Script Webアプリを生徒が開けるか」を確認してください。
2. URLをGoogleクラスルームで配ります。
3. iPadでは、Safariで開いて「共有ボタン → ホーム画面に追加」をすると、アプリのように使えます。

## 授業での使い方のポイント

- **授業の流れ**：はじめに先生が「📣 全体の学習課題」を出し、生徒は「🎯 学習課題」を立てます（ホームのいちばん上に表示されます）。授業中はつぶやきでコツを共有し、おわりに「📝 振り返り」を書きます。振り返りには、その日の学習課題が自動で入ります（書き直しもできます）。生徒は達成度（◎できた／○もう少し／△まだ）も選びます。
- **仮ログイン**：自分のアカウントでログインできない生徒は、共通アカウントでログインし、組と名前を選んで「先生の合言葉」を入れると、その生徒として使えます。共通アカウントは「設定 → 仮ログイン」で登録します。合言葉はホームの「🔑 合言葉」で確認でき、毎日変わります。何人でも同時に使えます。仮ログインしたことは「見守り」の記録に残ります。

- **投稿の受付**：ホームの上部のスイッチで、授業集団ごとに「受付中／停止」を切り替えます。停止中も、読むこととリアクションはできます。
- **見守り**：通報・承認待ち・削除の記録・NGワードでブロックされた投稿・投稿を一時停止中の生徒を確認できます。
- **バズ**：「今日」「全期間」のランキングです。先生だけが見られます。「発表モード」でテレビに映せます（下位から1位へ順に表示。名前を隠すこともできます）。
- **評価**：生徒を選ぶと、(a)振り返り (b)やってみた報告 (c)コツが生かされた投稿、できた技のチェックを見ながら、A・B・Cとメモを付けられます。「スプレッドシートに書き出す」で一覧表ができます。
- **動画**：生徒が振り返りに付けた動画（15秒・30MBまで）は「コツッター_提出動画（先生のみ）」フォルダに保存されます。投稿の「🎥 提出動画を見る」から開けます。

## プログラムを更新するとき

コピーする元のファイルは、次のリンクから開けます。開いた画面の右上にある **「Copy raw file」（📋のボタン）** を押すと、ファイルの中身が全部コピーされます。

- [Index.html（画面）](https://github.com/nagisa01-kobayashi/-_Claude/blob/claude/eager-maxwell-mwekin/gas/Index.html)
- [Code.gs（サーバー側）](https://github.com/nagisa01-kobayashi/-_Claude/blob/claude/eager-maxwell-mwekin/gas/Code.gs)

1. Apps Scriptの `Code.gs` と `Index.html` を、新しい中身に貼り替えて保存します。
2. **「デプロイ → デプロイを管理」→ ✏️（編集）→ バージョン「新バージョン」→「デプロイ」** を押します。
   - こうすると**URLは変わりません**（「新しいデプロイ」を押すとURLが変わってしまうので注意）。

## 知っておいてほしいこと

- **データの場所**：すべて共有ドライブ「コツッター」の中です。スプレッドシートを直接書き換えると、アプリが正しく動かなくなることがあるので、基本はアプリの画面から操作してください。
- **デプロイした先生が異動するとき**：アプリは「デプロイした先生のアカウント」で動いています。異動の前に、残る先生が手順2〜4（setupは不要）をやり直してください。データは共有ドライブに残るので消えません。
  - ※ 新しい先生がApps Scriptを作り直す場合は、同じスプレッドシートから「拡張機能 → Apps Script」を開き、`setup` を1回実行してから（既存のデータは消えません）デプロイしてください。
- **画面の更新**：新しい投稿は約20秒ごとに自動で読み込まれます。
- **年度が替わったら**：新しいスプレッドシートで作り直すのがかんたんです。前年度のデータはそのまま保存しておけます。

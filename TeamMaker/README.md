# チーム分けアプリ（Swift Playgrounds）

体育の授業向けのチーム分けアプリです。名簿は iPad の中だけに保存されます。

## できること
- Excel の名簿をまとめて貼り付けて読み込む（スポーツごとの列の ○ を `#サッカー` のようなタグにして取り込みます）
- 名簿で生徒ごとに参加のオン・オフを切り替える（欠席・見学）
- 性別（全員／男子／女子）と学級（例：2-2 と 2-4）で対象を絞り込む
- チーム数か、1チームの人数のどちらかでチームの数を決める
- 技能レベル（1〜5）の合計、男女の人数、指定した競技の経験者の数が、チームごとにそろうように分ける
- できたチームを A4 の PDF にして、共有シート（AirDrop・Google クラスルーム・Teams など）から生徒に送る
  - 技能レベルは、初期設定では PDF に載りません（スイッチで載せることもできます）

- 名簿と履歴は iPad の中に保存され、アプリを閉じても残ります（一度読み込めば、次回から読み込みは不要です）
- 「履歴に保存」したチームは「履歴」タブでいつでも見返せて、あとから PDF にして送り直せます

## 入れ方
1. iPad の Swift Playgrounds で「＋」から「App」を新規作成します。
2. 左の一覧から `ContentView.swift` を開き、中身をすべて消して、このフォルダの `ContentView.swift` の内容を貼り付けます。
3. 右側のプレビューで動作を確かめます。「読み込み」タブの「サンプルを入れてみる」から試せます。

## 名簿の作り方（Excel）
### おすすめ：アプリから入力用ファイルを書き出す
1. 「読み込み」タブの **「入力用の Excel ファイルを書き出す」** を押し、「ファイルに保存」するか Excel で開きます。
2. Excel で生徒を入力して保存します。
   - 性別（男／女）・レベル（1〜5）・スポーツの ○ は、セルのプルダウンから選べます。
   - 学級の列は「文字列」になっているので、「2-2」と入力しても日付に変わりません。
   - スポーツの列は、増やしたり名前を変えたりして構いません。
3. **「入力したファイルを読み込む」** でそのファイルを選び、読み取り結果を確認して「名簿を置き換える」か「今の名簿に追加する」を押します。

名簿を直したいときは **「今の名簿を Excel に書き出す」** で今の名簿を書き出し、直してから読み込み直して「置き換える」を押します。

読み込めるファイル：Excel（.xlsx）、CSV（.csv）、タブ区切り（.tsv・.txt）。Numbers のファイルは、Excel 形式で書き出してから読み込んでください。

### ほかの方法
- `名簿テンプレート.csv` を Excel で開いて入力することもできます。
- Excel で見出しの行ごと表をコピーして、「読み込み」タブの欄に貼り付けることもできます。
- 見出しが「学級・番号・名前・性別・レベル」以外の列は、すべてスポーツの列として読み込まれます。
- 「2-2」が日付（2月2日）に変わってしまっていても、アプリが「2-2」に戻して読み込みます。

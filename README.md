# こえアンプ 🎤

iPadのマイクに入った声を、リアルタイムでBluetoothスピーカーから大きく出すアプリです。

| 版 | 場所 | 必要なもの |
|---|---|---|
| **Webアプリ版（おすすめ）** | [`web/`](web/) | iPadのSafariだけ。インストール不要 |
| ネイティブ版 | [`ios-native/`](ios-native/) | Mac + Xcode |

## Webアプリ版の使い方

1. `web/` を https で公開します（例: GitHub Pages）。
   - リポジトリの Settings → Pages → Branch を選び、フォルダを `/ (root)` にして保存
   - `https://<ユーザー名>.github.io/<リポジトリ名>/web/` で開けます
2. iPadの設定 → Bluetooth でスピーカーを接続
3. SafariでページをひらきSafariの共有ボタン →「ホーム画面に追加」すると、アプリのように使えます
4. 「スタート」→ マイクを「許可」→ 音量スライダーで調整

### 機能
- 音量 ×0〜×8
- 入力レベルメーター
- ハウリング対策（180Hz以下の低音カット＋コンプレッサー/リミッター）
- ノイズ抑制のオン/オフ
- 使用中は画面が自動消灯しない
- 設定は次回も保持

### 注意
- **Bluetoothは仕組み上0.1〜0.3秒ほど遅れます**。話している本人には少しエコーのように聞こえることがあります。遅延を最小にしたい場合は有線スピーカー（Lightning/USB-C変換）が最適です。
- **ハウリング**（キーンという音）は、スピーカーをiPadから離し、マイクに向けないことで防げます。
- 画面を閉じたりSafariを切り替えると止まります。

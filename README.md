# 🤸 マット運動 AIコーチ

生徒が iPad で撮ったマット運動の動画を分析し、AIコーチ（Claude）がアドバイスを返す Web アプリです。
生徒が自分で動画を撮り、アドバイスを読み、ふりかえりを書けるように作っています。

## できること

1. **技を選ぶ**：前転、開脚前転、伸膝前転、後転、開脚後転、伸膝後転、側方倒立回転、倒立前転、補助倒立・壁倒立から選びます。「今日のめあて」も書けます。
2. **動画を撮る・選ぶ**：iPad のカメラで撮るか、写真アプリから選びます。
3. **骨格の分析**：iPad の中で関節の位置を推定し、膝・腰・肘・首の角度や体の傾きを計算します。
4. **ふりかえり**
   - 動画に骨格を重ねて表示します。0.25倍・0.5倍のスロー再生とコマ送りができます。
   - 大事な場面（逆さまになったところ、立ち上がるところなど）を自動で選び、タップでその場面へ移動します。
   - AIコーチが「よかったところ」「もっとよくなるポイント（その場面へ移動するボタン付き）」「次にやってみる練習」を返します。
   - 生徒が自己評価と「次にがんばること」を書いて記録します。記録はその iPad の中にだけ保存されます。

## 個人情報への配慮

- **動画はどこにも送信しません。** 骨格の推定は iPad のブラウザの中だけで行います。
- AIコーチ（Claude API）に送るのは次の3つだけです。
  - 角度などの**数値**
  - 顔や服装が写らない**棒人間の画像**（5〜8枚）
  - 生徒が書いた「めあて」
- 名前などの個人を特定する情報は入力しません。
- 学校で使う前に、外部の AI サービスにデータを送ることが学校や自治体のルールで認められているか、確認してください。

## 準備（先生用）

### 必要なもの

- Node.js 20 以上が入ったパソコン（校内の先生用 PC など）
- Anthropic の API キー（<https://console.anthropic.com/> で発行）
- パソコンと iPad が同じネットワークにつながっていること

### 起動のしかた

```bash
npm install
```

```bash
ANTHROPIC_API_KEY=発行したキー APP_PASSCODE=好きな合言葉 npm start
```

起動したら、iPad の Safari で `http://（パソコンのIPアドレス）:8080` を開きます。
「共有」→「ホーム画面に追加」をしておくと、アプリのように使えます。

### お試しモード

API キーがなくても、画面や操作をひと通り試せます。
このモードでは、AIコーチは決まった見本の回答を返します。骨格の分析は本物です。

```bash
npm run mock
```

### 設定できること（環境変数）

| 名前 | 内容 | 初期値 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | Claude の API キー | （必須） |
| `APP_PASSCODE` | 設定すると、合言葉を入れた iPad だけが使えます | なし |
| `PORT` | サーバーのポート番号 | 8080 |
| `LIMIT_PER_HOUR` | 1台あたり1時間に分析できる回数 | 60 |
| `COACH_MODEL` | 使う Claude のモデル | `claude-opus-5-5` |
| `MOCK_COACH` | `1` にするとお試しモード | なし |

### 費用の目安

1回の分析で送るのは、文字と小さい画像が数枚です。
費用は**1回あたりおよそ10〜20円程度**の見込みです（回答の長さによって変わります）。
最新の料金は Anthropic の料金ページで確認してください。

## 撮影のコツ（生徒に伝えること）

- **真横**から撮る（マットの長い辺の横に立つ）
- 始めから終わりまで、**頭から足まで全身**が映るようにする
- iPad は**横向き**にして、動かさずに持つ
- マットから **3〜5m** 離れる
- 映るのは**演技する人だけ**にする
- 1回の技だけを撮る（30秒以内）

## 先生がカスタマイズできるところ

- `public/skills.js`：技ごとの「ポイント」と「よくあるつまずき」です。ふだんの授業の言葉に書きかえると、AIコーチのアドバイスもその言葉に沿った内容になります。技を増やすこともできます。
- `server.js` の `SYSTEM_PROMPT`：AIコーチの話し方やアドバイスの方針です。

## しくみ

```
iPad（ブラウザ）                         サーバー（先生のPC）          Claude API
 動画 → MediaPipe で骨格推定
      → 角度・場面を計算
      → 棒人間の画像を作る  ── 数値＋棒人間 ──▶  /api/coach  ──────▶  アドバイスを生成
 骨格つき動画＋アドバイスを表示 ◀──────── アドバイス（JSON） ◀────────
```

| ファイル | 役割 |
| --- | --- |
| `public/index.html` `public/style.css` `public/app.js` | 画面と操作 |
| `public/analyze.js` | 骨格推定（MediaPipe Pose Landmarker）、角度の計算、場面の選び出し、棒人間の描画 |
| `public/skills.js` | 技とポイントの一覧 |
| `server.js` | 画面の配信と、Claude API への問い合わせ |

## 気をつけること

- 前転や後転のように体が丸まったり逆さまになったりする場面では、骨格の推定がずれやすくなります。AIコーチには、数値が不確かなときは決めつけないように指示しています。
- アドバイスは「気づきのきっかけ」です。安全面の指導や評価は、先生が行ってください。

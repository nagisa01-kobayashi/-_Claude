# 🤸 マット運動コーチ

生徒が iPad で撮ったマット運動の動画を分析し、コーチのようにアドバイスを返す Web アプリです。
生徒が自分で撮影し、アドバイスを読んでふりかえりを書けるように作っています。

- **無料**：有料のサービスや API は使いません。
- **iPad の Safari だけで動く**：アプリのインストールは不要です。ホーム画面に追加すれば、アプリのように使えます。
- **動画を外部に送らない**：分析はすべて iPad の中で行います。
- **オフラインでも使える**：一度開けば、体育館などでインターネットがなくても使えます。

## できること

1. **技を選ぶ**：前転、開脚前転、伸膝前転、後転、開脚後転、伸膝後転、側方倒立回転、倒立前転、補助倒立・壁倒立から選びます。「今日のめあて」も書けます。
2. **動画を撮る・選ぶ**：iPad のカメラで撮るか、写真アプリから選びます。
3. **骨格の分析**：iPad の中で関節の位置を推定し、ひざ・腰・ひじ・首の角度や体の傾きを計算します。
4. **ふりかえり**
   - 動画に骨格を重ねて、0.25倍・0.5倍のスローやコマ送りで見られます。
   - 大事な場面（逆さまになったところ、立ち上がるところなど）を自動で選び、タップでその場面へ移動します。
   - コーチが技ごとのチェック項目（◎できている／△もう少し／－判定できない）を示します。あわせて「よかったところ」「もっとよくなるポイント（その場面へ移動するボタン付き）」「次にやってみる練習」を返します。
   - 「めあて」のことば（例：「あご」「手」「ひざ」）を読み取り、めあてが達成できたかにもふれます。
   - 生徒が自己評価と「次にがんばること」を書いて記録します。記録はその iPad の中にだけ保存されます。

## コーチのしくみ

コーチのコメントは、生成AIではなく、**先生が決めたチェック項目と目安**にもとづいて作ります（`public/coach.js`）。

- 例：前転では「あごを引けているか」「背中が丸まっているか」「腰を高く上げてから回り始めたか」「立ち上がれたか」「手をつかずに立てたか」を判定します。
- 首を痛めるおそれのある動き（あごが上がる、後転で手で押せていない、倒立でひじが曲がる）を、いちばん先に伝えます。
- いちばん大事なポイントに合わせて、「ゆりかご」「坂道マットで前転」などの練習を提案します。すべてできていれば、次の技（例：前転 → 開脚前転）をすすめます。

## 使い始めるまで（先生用）

### 1. 無料で公開する（GitHub Pages）

1. このリポジトリを **Public（公開）** にします。GitHub の無料プランで Pages を使うには公開リポジトリが必要です。公開されるのはアプリのプログラムだけで、生徒の動画や記録は含まれません。
2. GitHub のリポジトリで **Settings → Pages** を開き、「Source」を **GitHub Actions** にします。
3. `main` ブランチに反映すると、自動で公開されます。公開先は `https://（ユーザー名）.github.io/（リポジトリ名）/` です。

### 2. iPad で開く

1. iPad の Safari で、公開された URL を開きます。
2. 「共有」ボタン →「ホーム画面に追加」を押すと、アプリのアイコンができます。
3. 最初の1回はインターネットにつながった状態で開きます（約30MBを読み込みます）。2回目からは、インターネットがなくても使えます。

> 学校の iPad を MDM（端末の一括管理）で管理している場合は、URL を Web クリップとして全台に配布することもできます。

### 手元で試す場合

`public` フォルダを Web サーバーで開けば動きます（パソコンのブラウザでも確認できます）。

```bash
cd public && python3 -m http.server 8080
```

## 撮影のコツ（生徒に伝えること）

- **真横**から撮る（マットの長い辺の横に立つ）
- 始めから終わりまで、**頭から足まで全身**が映るようにする
- iPad は**横向き**にして、動かさずに持つ
- マットから **3〜5m** 離れる
- 映るのは**演技する人だけ**にする
- 1回の技だけを撮る（30秒以内）

## 先生がカスタマイズできるところ

| ファイル | 内容 |
| --- | --- |
| `public/skills.js` | 技の一覧と、技ごとの「ポイント」「よくあるつまずき」（技を選んだときに表示されます） |
| `public/coach.js` | チェック項目、判定の目安（角度のしきい値）、コメントのことば、練習メニュー |

ファイルを書きかえたら、`public/sw.js` の `VERSION`（例：`"v1"` → `"v2"`）を上げてください。上げると、iPad に新しい内容が届きます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `public/index.html` `public/style.css` `public/app.js` | 画面と操作 |
| `public/analyze.js` | 骨格推定、角度の計算、場面の選び出し、棒人間の描画 |
| `public/coach.js` | コーチのコメントを作る |
| `public/skills.js` | 技とポイントの一覧 |
| `public/sw.js` `public/manifest.webmanifest` `public/icons/` | ホーム画面への追加とオフライン対応 |
| `public/vendor/` | 骨格推定のプログラムとモデル（[MediaPipe](https://github.com/google-ai-edge/mediapipe)、Apache License 2.0） |

## 気をつけること

- 前転や後転のように体が丸まったり逆さまになったりする場面では、骨格の推定がずれやすくなります。判定できないポイントは「－」と表示し、決めつけないようにしています。
- 判定の目安は一般的な値から設定した初期値です。実際の生徒の動画で試しながら、`public/coach.js` で調整してください。
- アドバイスは「気づきのきっかけ」です。安全面の指導や評価は、先生が行ってください。

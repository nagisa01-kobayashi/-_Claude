# -_Claude

保健体育の授業づくりを Claude と一緒に進めるためのリポジトリです。

- 授業案・ワークシートなどの実体は Google Drive の「仕事管理」→「保健体育授業」フォルダ(単元ごとのサブフォルダ)に保存します。**Google Drive が正**です。
- このリポジトリには、同じ内容を `.md` として保存し、変更履歴を追えるようにします。**GitHub は履歴管理用**です。
- 「〇〇の授業を行いたい」と話しかけたときの自動対応(単元フォルダの確認・作成、条件整理、授業案作成、アイディア収集など)は、Claude のスキル `pe-lesson-assistant` が担当します。スキルの中身と使い方は [`docs/pe-lesson-automation.md`](docs/pe-lesson-automation.md) を参照してください。

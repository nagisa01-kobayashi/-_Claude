技ビデオ 自動録画の設定ガイド

マットや跳び箱の範囲で人が動くと録画が始まり、止まると自動で終わって先生のGoogleドライブに保存されます。最初に一度だけ、Google Apps Script にコードを貼り付けて公開してください。15分ほどで終わります。

撮影用の端末（カメラ1〜4）→先生のGoogleドライブ「技ビデオ」→別の端末で一覧を見る

  1. Apps Script のプロジェクトを作る

    パソコンで学校のGoogleアカウントにログインし、script.google.com を開いて 新しいプロジェクト を押します。左上の「無題のプロジェクト」を押して「技ビデオ」などの名前にします。

  2. 「コード.gs」を貼り付ける

    最初から入っている function myFunction() {…} をすべて消し、下の中身を貼り付けます。

  3. 「index.html」を作って貼り付ける

    左の「ファイル」の横の ＋ → HTML を選び、名前を index にします（.html は自動で付きます）。中身をすべて消して、下を貼り付けます。

  4. 保存して、ドライブの使用を許可する

    保存ボタン（フロッピーの絵）を押します。上の関数の選択欄で setup を選び、実行 を押します。

    「承認が必要です」と出たら、自分のアカウントを選んで許可します。「このアプリは Google で確認されていません」と出た場合は 詳細 → 技ビデオ（安全ではないページ）に移動 → 許可 の順に進みます。自分で作ったスクリプトなので問題ありません。

    実行ログに「保存先フォルダ: https://drive.google.com/…」と出れば成功です。ドライブに「技ビデオ」フォルダができています。

  5. ウェブアプリとして公開する

    右上の デプロイ → 新しいデプロイ を押し、歯車から種類に ウェブアプリ を選びます。

    • 次のユーザーとして実行：自分
    • アクセスできるユーザー：（学校のドメイン）内の全員

    デプロイ を押すと、https://script.google.com/a/macros/…/exec のようなURLが出ます。これがアプリのURLです。コピーしておきます。

    撮影用の端末も見る端末も、学校のGoogleアカウントでログインしたブラウザで開いてください。

  6. 撮影用の端末で開く

    iPad などでアプリのURLを開き、カメラ1 → 撮影する を押します。カメラの使用を聞かれたら 許可 します。

    • 端末は三脚などで横向きに固定し、マットや跳び箱の全体が映るように置きます。
    • 映像の上を指でなぞって、動きを見る範囲を囲みます。待っている人や通る人が入らない範囲にすると、間違って録画が始まりにくくなります。
    • 種目と技を選んで 自動録画をはじめる。範囲の中で動くと赤い「録画中」になり、止まって2秒ほどで保存されます。
    • 反応しすぎる・しなさすぎる時は「感度の調整」で変えられます。
    • 録画中は画面を開いたままにし、充電しながら使ってください。

  7. 別の端末で一覧を見る

    ホーム画面の各カメラの「一覧を見る」のリンク（URLの最後が ?list=2 など）を開くと、そのカメラで撮った映像がすべて並びます。20秒ごとに新しい映像を確認します。

    撮った直後はGoogleドライブが映像を処理しているため、再生できるまで1〜2分かかることがあります。

カメラが使えないとき

学校の端末やブラウザの設定によっては、Apps Script の画面の中でカメラが使えないことがあります。その場合は「この画面ではカメラが使えません」と表示されます。

そのときは index.html をカメラが使える別の場所（GitHub Pages など）に置き、Apps Script はデータの保存だけに使う方法に切り替えられます。この方法ではデプロイの「アクセスできるユーザー」を「全員」にする必要があるため、コード.gs の UPLOAD_KEY に合言葉を入れて使います。切り替えが必要になったら声をかけてください。

知っておくこと

  • 映像は先生のGoogleドライブの容量を使います。720pで1本10秒ならおよそ3MBです。
  • 「技ビデオ」フォルダは学校のドメイン内で閲覧できるよう共有されます（見る端末で再生するため）。共有したくない場合は、コード.gs の SHARE_IN_DOMAIN を false にしてから setup を実行してください。
  • 技名の修正と削除は、アプリを作った先生のアカウントだけができます。削除した映像はドライブのゴミ箱に入り、30日以内なら戻せます。
  • コードを直した時は デプロイ → デプロイを管理 → 鉛筆 → バージョン「新バージョン」→ デプロイ で反映されます。URLは変わりません。
  • 生徒の映像を扱うため、学校の個人情報の取り扱いの決まりを確認してから使ってください。

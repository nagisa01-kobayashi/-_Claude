技ビデオ 自動録画の設定ガイド

マットや跳び箱の範囲で人が動くと録画が始まり、止まると自動で終わって先生のGoogleドライブに保存されます。Apps Script の画面の中ではカメラが使えないため、撮影だけは GitHub Pages に置いた撮影用ページで行います。

撮影用ページ（GitHub Pages）→Apps Script（保存用）→Googleドライブ「技ビデオ」→Apps Script（一覧・再生）
すでに手順5まで済ませた方は、A〜E だけ行ってください。

  1. A. コードを新しいものに入れ替える

    Apps Script の「コード.gs」と「index.html」の中身をそれぞれすべて消して、下を貼り付け直し、両方とも保存します。

  2. B. 今のデプロイを更新する（見る用）

    デプロイ → デプロイを管理 → 鉛筆 → バージョン 新バージョン → デプロイ。アクセスは「（学校のドメイン）内の全員」のままです。このURLがアプリのURL（ホーム・一覧）になります。

  3. C. 保存用のデプロイをもう1つ作る

    デプロイ → 新しいデプロイ → 種類 ウェブアプリ。

    • 次のユーザーとして実行：自分
    • アクセスできるユーザー：全員

    出てきたURL（…/exec）が保存用のURLです。コピーしておきます。

    「全員」にしても、合言葉（自動で作られます）を持つ撮影用ページからしか保存や一覧の取得はできません。映像そのものは先生のドライブにあり、学校のドメイン外からは見られません。
    「全員」が選べない場合は、学校の管理者が制限しています。その場合は教えてください。別の方法を考えます。

  4. D. 撮影用ページを公開する（GitHub Pages）

    撮影用ページはリポジトリの docs/index.html に入れてあります。GitHub で次の2つを行います。

    • リポジトリの Settings → General の一番下 → Change visibility → Public（GitHub Pages は無料プランでは公開リポジトリのみ使えます）
    • Settings → Pages → Source Deploy from a branch、Branch claude/clever-ramanujan-b8d2w7、フォルダ /docs → Save

    1〜2分後、https://nagisa01-kobayashi.github.io/-_Claude/ が撮影用ページのURLになります。

    ページにはコードだけが入っていて、合言葉や映像は入っていません。リポジトリを公開したくない場合は、公開用の新しいリポジトリを作る方法もあります。

  5. E. アプリに2つのURLを登録する

    アプリのURL（B）を開くと、ホームに「撮影用ページの設定」が出ます。撮影用ページのURL（D）と保存用のURL（C）を入れて 保存 します。

  6. 撮影する

    撮影用のiPadでアプリのURLを開き、カメラ1 → 撮影する を押します。撮影用ページが開くので、カメラを 許可 します。この時に保存先がiPadに記録されるので、次からは撮影用ページを直接開いても使えます。

    • iPadは三脚などで横向きに固定し、マットや跳び箱の全体が映るように置きます。
    • 映像の上を指でなぞって、動きを見る範囲を囲みます。待っている人が入らない範囲にすると誤作動が減ります。
    • 種目と技を選んで 自動録画をはじめる。動くと「録画中」になり、止まって2秒ほどで保存されます。
    • 録画中は画面を開いたまま、充電しながら使ってください。

  7. 見る

    別の端末でアプリのURLを開き、カメラの「一覧を見る」を押します（URLの最後が ?list=2 など）。撮った直後は、ドライブの処理のため再生できるまで1〜2分かかることがあります。

知っておくこと

  • 映像は先生のGoogleドライブの容量を使います。720pで1本10秒ならおよそ3MBです。
  • 「技ビデオ」フォルダは学校のドメイン内で閲覧できるよう共有されます。共有したくない場合は、コード.gs の SHARE_IN_DOMAIN を false にしてください。
  • 技名の修正と削除は、アプリを作った先生のアカウントだけができます。削除した映像はドライブのゴミ箱に入り、30日以内なら戻せます。
  • コードを直した時は、BとCの両方のデプロイで「新バージョン」にしてください。URLは変わりません。
  • 生徒の映像を扱うため、学校の個人情報の取り扱いの決まりを確認してから使ってください。

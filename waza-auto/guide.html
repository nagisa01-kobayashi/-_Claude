技ビデオ 設定ガイド

iPadのカメラで撮った技の動画を、確認なしですぐ先生のGoogleドライブに保存し、URLを知っている人が別の端末で見られるアプリです。クラスは最初に選び（複数可）、撮影画面では技と氏名を選んで撮ります。

ホームでカメラ番号とクラスを選ぶ→技を選び氏名を入れて撮る→Googleドライブ「技ビデオ／クラス」→一覧で見る

  1. コードを入れ替える

    script.google.com で「技ビデオ」を開き、「コード.gs」と「index.html」の中身をそれぞれ全部消して、下を貼り付けます。両方とも保存ボタンを押します。

  2. アプリのデプロイを新バージョンにする

    デプロイ → デプロイを管理 → アクセスが「city-niigata.ed.jp 内の全員」のもの（URLに AKfycbz0wSz を含む）を選ぶ → 鉛筆 → バージョン 新バージョン → デプロイ。

    URLは変わりません。このURLがアプリのURLです。

  3. 使わなくなったデプロイを止める

    同じ「デプロイを管理」で、アクセスが「全員」のもの（URLに AKfycby5L4 を含む）を選び、右上の アーカイブ（箱の絵）を押します。ほかに使っていない「無題」があれば、それもアーカイブして構いません。

    「city-niigata.ed.jp 内の全員」のものはアーカイブしないでください。

  4. GitHub を元に戻す（任意）

    撮影用ページは使わなくなりました。Pages の設定で Branch を None にして Save し、General の一番下で Change to private にすると、元の非公開に戻せます。

  5. 技の選択肢を整える

    アプリのURLを開き、ホームの「先生用」→ 技の選択肢を編集 で、授業で扱う技に合わせて追加・削除・並べ替えをして 保存 します。この画面は、アプリを作った先生のアカウントでだけ表示されます。

授業での使い方

  • はじめに：iPadでアプリのURLを開き、カメラ番号と授業のクラスを選んで 撮影画面へ。合同授業などは、クラスを複数選べます。
  • 撮影画面：選んだクラスは固定されます（複数選んだときは、動画ごとにどのクラスかを押して切り替え）。種目と技を押し、氏名を入れて iPadのカメラで撮る。
  • 撮り終えたら「ビデオを使用」を押します。iPadの仕組み上このボタンは省けませんが、押した瞬間に保存が始まり、アプリ側での確認はありません。
  • 保存中でも続けて次の人を撮れます。氏名は1本ごとに空になり、技はそのまま残ります。
  • 見る：ホームの「撮った映像を見る」から開きます。クラス・カメラ・種目・技で絞り込み、この一覧のURLをコピー で送ると、別の端末でも同じ一覧が開けます（学校のGoogleアカウントでログインしている端末）。

知っておくこと

  • 動画は先生のGoogleドライブの「技ビデオ」フォルダに、クラスごとに保存されます。
  • 1本40MBを超える動画は保存に失敗することがあります。10〜20秒程度で撮るか、iPadの「設定 → カメラ → ビデオ撮影」を「1080p/30fps」にしてください。
  • 技・氏名の修正と削除は、アプリを作った先生のアカウントだけができます。削除した動画はドライブのゴミ箱に入り、30日以内なら戻せます。
  • 生徒の映像を扱うため、学校の個人情報の取り扱いの決まりを確認してから使ってください。
